# Glossary — Technical SEO

**Date:** 2026-07-13. Single source of terminology for `seo-engineer/`. Terms link to the doc that treats them in depth.

- **Canonical / canonicalization** — the process (and the `rel=canonical` hint) of designating one URL as the authoritative version among duplicates/variants, so ranking signal consolidates there. Google treats the tag as a *hint* and may choose its own canonical. Depth: [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md) §3.
- **ccTLD** — country-code top-level domain (`example.de`); the strongest but costliest geo-targeting signal. [`topics/international-seo/`](topics/international-seo/production-patterns.md).
- **Click depth** — minimum number of link hops from the homepage to a page; a crawl-priority and importance signal. Budget: priority pages ≤3. [`principles/site-architecture.md`](principles/site-architecture.md) §3.
- **Cloaking** — serving different content to crawlers than to users; a spam-policy violation. Geo-redirects and UA-conditional serving drift toward it. [`principles/rendering-strategy.md`](principles/rendering-strategy.md).
- **CLS (Cumulative Layout Shift)** — Core Web Vital measuring visual stability; Good ≤ 0.1 at p75. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Core Web Vitals (CWV)** — Google's page-experience metric set (LCP, INP, CLS), measured on field data, a modest ranking input. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Crawl budget** — the request volume Google allocates a site (crawl-rate limit × crawl demand); a practical constraint only at large scale (~500K+ URLs) or with unbounded URL spaces. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md) §2.
- **Crawl trap** — a URL space that grows combinatorially (facets × sorts × pages, infinite calendars) and consumes crawl budget on worthless permutations. [`principles/site-architecture.md`](principles/site-architecture.md) §2.
- **CrUX (Chrome UX Report)** — Google's aggregated real-Chrome-user field-data set; the source of the CWV numbers ranking actually uses; trailing 28 days. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Dynamic rendering** — serving prerendered HTML to bots by user-agent detection; deprecated by Google, don't build it. [`principles/rendering-strategy.md`](principles/rendering-strategy.md).
- **Dynamic serving** — one URL, UA-varied HTML (mobile vs desktop); legacy mobile architecture requiring `Vary: User-Agent` and strict parity. [`topics/mobile-first-indexing/`](topics/mobile-first-indexing/production-patterns.md) Pattern 2.
- **Faceted navigation** — filter/sort UI that mints URL permutations; the main crawl-trap generator on commerce sites. [`principles/site-architecture.md`](principles/site-architecture.md) §2.
- **Field data vs lab data** — real-user measurements (CrUX, RUM) vs synthetic tool runs (Lighthouse). Ranking uses field; lab is for debugging and CI regression tripwires only. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md) §1.
- **GSC (Google Search Console)** — Google's site-owner diagnostics: index state, performance, manual actions, CWV, enhancement reports. Workflow: [`principles/monitoring-diagnosis.md`](principles/monitoring-diagnosis.md).
- **hreflang** — bidirectional annotations declaring language/region alternates of a page so the right locale ranks per market; fails silently on missing return tags or invalid codes. [`topics/international-seo/`](topics/international-seo/production-patterns.md) Pattern 2.
- **Hydration (mismatch)** — client JS attaching to server-rendered HTML; a mismatch between the two can change what gets indexed. SEO angle: [`principles/rendering-strategy.md`](principles/rendering-strategy.md) §2; mechanics: [`../web-dev/`](../web-dev/README.md).
- **Indexability** — whether a crawled page is eligible to enter the index (no `noindex`, canonical to self, 200, quality bar). The four gates: discovered → crawled → rendered → indexed. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md).
- **INP (Interaction to Next Paint)** — Core Web Vital for responsiveness; Good ≤ 200ms at p75; replaced FID (2024); measurable only via real interactions (field/RUM). [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **JSON-LD** — Google's recommended structured-data format: a `<script type="application/ld+json">` block, ideally server-rendered. [`principles/structured-data.md`](principles/structured-data.md).
- **LCP (Largest Contentful Paint)** — Core Web Vital for load speed of the main content element; Good ≤ 2.5s at p75. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Manual action** — a human-applied Google penalty (reported in GSC), e.g. for spammy structured markup; recovery via fix + reconsideration request, measured in weeks. [`principles/structured-data.md`](principles/structured-data.md) §2.
- **Mobile-first indexing** — Google indexes and ranks from the smartphone-Googlebot rendering of every page (universal since 2023). [`topics/mobile-first-indexing/`](topics/mobile-first-indexing/production-patterns.md).
- **noindex** — page-level directive (meta robots or `X-Robots-Tag` header) excluding a page from the index; only works on crawlable pages. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md).
- **Orphaned page** — a page with no internal links pointing to it; receives no link equity and decays regardless of quality. Detection is a set-difference. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md) §4.
- **p75 (75th percentile)** — the aggregation point at which CWV is judged: the metric value that 75% of page loads beat. Why office-wifi testing misleads. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Redirect chain** — multi-hop redirect sequences (A→B→C); each hop wastes crawl and leaks signal; migrations must collapse to one hop. [`topics/site-migrations/common-pitfalls.md`](topics/site-migrations/common-pitfalls.md) #4.
- **Render-blocking resource** — CSS/JS that delays first paint (and thus LCP). SEO threshold framing here; fixes in [`../web-dev/principles/performance.md`](../web-dev/principles/performance.md).
- **Rendering (two-phase)** — Googlebot's pipeline: immediate HTML parse, deferred JS execution in evergreen Chromium. Content that exists only post-JS indexes later and less reliably. [`principles/rendering-strategy.md`](principles/rendering-strategy.md).
- **Rich result** — enhanced SERP display (stars, prices, breadcrumbs…) earned by eligible, valid, truthful structured data; feature types churn — verify current support. [`principles/structured-data.md`](principles/structured-data.md).
- **robots.txt** — crawl-permission file at the host root; controls *crawling*, not indexing — a disallowed page can still be indexed, and its `noindex` can't be seen. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md).
- **RUM (Real User Monitoring)** — your own field-data pipeline (e.g. the `web-vitals` library → analytics); real-time leading indicator vs CrUX's 28-day lag. [`principles/core-web-vitals-seo.md`](principles/core-web-vitals-seo.md).
- **Soft 404** — a page Google judges to be an error/empty result served with a 200 (or an irrelevant redirect target, e.g. mass homepage redirects); passes no signal. [`topics/site-migrations/common-pitfalls.md`](topics/site-migrations/common-pitfalls.md) #2.
- **SSR / SSG / CSR / ISR** — server-side rendering / static generation / client-side rendering / incremental static regeneration; the rendering-mode menu. Search consequences: [`principles/rendering-strategy.md`](principles/rendering-strategy.md); implementation: [`../web-dev/frameworks/`](../web-dev/README.md).
- **Structured data** — machine-readable page metadata (schema.org vocabulary) enabling rich results; must be valid, eligible, and truthful — three different bars. [`principles/structured-data.md`](principles/structured-data.md).
- **URL parameter** — query-string component; each one is either a real page (crawlable, canonical) or a duplicate/trap to be excluded — decided by policy, not accident. [`principles/site-architecture.md`](principles/site-architecture.md) §2.
- **x-default** — the hreflang value naming the fallback page for users matching no declared locale. [`topics/international-seo/production-patterns.md`](topics/international-seo/production-patterns.md).
- **X-Robots-Tag** — HTTP-header form of robots directives; applies to non-HTML and is set at server/CDN level, where app-level tests don't look — a classic invisible-noindex vector. [`principles/crawlability-indexability.md`](principles/crawlability-indexability.md) §1.
- **410 (Gone)** — the honest "permanently removed" status; preferred over redirect-to-irrelevant for content with no successor. [`topics/site-migrations/production-patterns.md`](topics/site-migrations/production-patterns.md) Phase 2.
